## Part 3: MVC Frontend & Docker

### Running Locally
1. Start the Part 2 API: `cd Part2-API/RaceDay.Api` then `dotnet run`
2. Start the Part 3 Web App: `cd RaceDay.Web` then `dotnet run`
3. Open browser at `http://localhost:5021`

### Running with Docker
1. Ensure Docker Desktop is running.
2. Run `docker-compose up --build` in the root directory.
3. Access the app at `http://localhost:5081`.
